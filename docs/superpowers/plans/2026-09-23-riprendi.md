# riprendi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `riprendi` command plus a `systemd --user` watcher that resumes marked Claude Code sessions a few minutes after their usage limit resets.

**Architecture:** Pure functions (limit detection, reset-time parsing, resume decision) in small modules, unit-tested with `unittest`; thin I/O layers (session files, state file, subprocess, notify-send) around them; an `argparse` CLI.

**Tech Stack:** Python 3.13 standard library only (`json`, `zoneinfo`, `argparse`, `subprocess`, `unittest`), systemd user service.

**Spec:** `docs/superpowers/specs/2026-09-23-riprendi-design.md`

## Global Constraints

- Standard library only, no third-party packages.
- Resume command exactly: `claude --resume <id> -p "Il limite di utilizzo si e' sbloccato: continua da dove eri rimasto. Se il lavoro era finito, dillo e fermati." --permission-mode auto`, run in the session's `cwd`.
- Resume 2 minutes after the parsed reset; unparsable text → 30 minutes after the error.
- At most 3 consecutive resumes ending on a new limit error, then status `ferma: troppi tentativi`.
- Never resume when the limit error is no longer the last significant event (someone resumed by hand).
- Never `bypassPermissions`. No credentials read or stored.
- State in `~/.local/state/riprendi/state.json`, logs in `~/.local/state/riprendi/logs/` (overridable with `RIPRENDI_HOME` for tests); sessions in `~/.claude/projects` (overridable with `RIPRENDI_PROJECTS`).
- Comments in Italian, CLI messages in Italian. Conventional commits, targeted `git add`, no AI trailers.

## Review Focus

1. A session line half-written when read (truncated JSON) must be skipped, not crash the watcher (Task 2 test).
2. Reset time already past at parse time ("resets 11am" read at 11:30) → tomorrow, not in the past (Task 1 test).
3. Two watcher ticks while a resume is still running → one resume only (Task 3 test).
4. `segui` in a folder with several sessions picks the most recently modified one, ignoring `subagents/` (Task 2 test).
5. `claude` missing from PATH → status `errore` and a notification, no crash loop (Task 4 test).

---

### Task 1: Limit detection and reset parsing — `riprendi/limits.py`

**Interfaces — produces:** `is_limit_event(event: dict) -> bool`, `limit_text(event: dict) -> str`, `event_time(event: dict) -> datetime` (aware UTC), `parse_reset(text: str, after: datetime) -> datetime | None` (aware), `RESUME_DELAY = timedelta(minutes=2)`, `FALLBACK_DELAY = timedelta(minutes=30)`, `resume_at(event: dict) -> datetime`.

Tests (`tests/test_limits.py`): the real 2026-09-23 record is a limit event; a normal assistant message is not; `isApiErrorMessage` with another `error` is not; `resets 11am (Europe/Rome)` after 05:53Z → 09:00Z same day; `resets 3:30pm (Europe/Rome)`; `resets 15:00` (local zone); after 11:30 Rome → next day 11:00; unknown text → None; `resume_at` = reset + 2 min, fallback = error + 30 min.

### Task 2: Session files — `riprendi/sessions.py`

**Produces:** `last_significant_event(path: Path) -> dict | None` (last line with `type` in `user`/`assistant`, bad JSON lines skipped), `find_session_for_cwd(cwd: str, projects: Path) -> tuple[str, Path] | None`, `find_session(session_id: str, projects: Path) -> Path | None`, `session_cwd(path: Path) -> str | None`.

Tests: truncated last line ignored; `system`/`summary` lines ignored; most recent session for a cwd chosen; `subagents/` files ignored; unknown id → None.

### Task 3: State and decision — `riprendi/state.py`, `riprendi/decide.py`

**Produces:** `@dataclass Tracked(session_id, path, cwd, status="attiva", attempts=0, next_at=None, error_uuid=None, pid=None)`; `load(home) -> dict[str, Tracked]`, `save(home, tracked)`; `decide(t: Tracked, event: dict | None, now: datetime, running: bool) -> Decision` where `Decision(kind: Literal["nulla","attendi","riprendi","ferma"], at: datetime | None)` and `decide` also updates `t` (status, attempts, next_at, error_uuid).

Rules: no limit event → `attiva`, attempts reset to 0, `nulla`; running → `nulla`; limit event with a new uuid after a resume → attempts += 1; attempts >= 3 → `ferma`; now < resume_at → `attendi`; else `riprendi`.

### Task 4: Resume and notify — `riprendi/resume.py`

**Produces:** `PROMPT`, `build_command(session_id) -> list[str]`, `start(t: Tracked, logs: Path) -> int` (Popen in `t.cwd`, stdout+stderr to `logs/<id>-<ts>.log`, returns pid; raises `FileNotFoundError` when `claude` is missing), `is_running(pid) -> bool`, `notify(title, body)` (never raises).

### Task 5: CLI and watcher — `riprendi/cli.py`, `riprendi/__main__.py`, `riprendi.service`, `install.sh`

`segui`, `smetti`, `stato`, `sorveglia [--once]`, `installa`. The watcher tick: for each tracked session read the last event, `decide`, act (start resume / notify on stop), save state; sleep 60 s. End-to-end test with a fake `claude` script on PATH writing a new assistant line into the session file.
